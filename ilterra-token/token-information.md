## Official token identity

The ILTERRA token is identified by its **Jetton master contract address** on TON Mainnet. A name, symbol or image alone is not proof that another token is authentic.

| Attribute | Value |
| --- | --- |
| Token name | ILTERRA |
| Symbol | ILT |
| Network | TON Mainnet |
| Token standard | Jetton (TEP-74) |
| Decimals | 9 |
| Initial mint | 10,000,000 ILT |
| Jetton master contract | `EQALRGN8_jJg1dydiWckdiOpTXyUBi0tjBH71QpC6BEHkFLu` |
| Additional minting | Enabled in the deployed contract while its administrator retains that permission |
| Official image | [256 × 256 transparent PNG](/assets/brand/ilterra_coin.png) |

**Full Jetton master address:** `EQALRGN8_jJg1dydiWckdiOpTXyUBi0tjBH71QpC6BEHkFLu`

Inspect the contract in [Tonviewer](https://tonviewer.com/EQALRGN8_jJg1dydiWckdiOpTXyUBi0tjBH71QpC6BEHkFLu) or read its [live TON API data](https://tonapi.io/v2/jettons/EQALRGN8_jJg1dydiWckdiOpTXyUBi0tjBH71QpC6BEHkFLu).

## Supply and administration

The first mint created 10,000,000 ILT. The on-chain total supply was also 10,000,000 ILT when this page was prepared. **That number is not a guaranteed maximum.** Supply can change through further minting or burning. The deployed contract reports that minting is enabled and that an administrator address is present. A proposed voting policy does not currently restrict these contract permissions.

For a current supply figure or administrator status, use the live contract links above. The figures in this document describe the initial issuance and the contract state observed while preparing the page; they are not a live feed.

## How to verify a token

Before receiving or using an ILT token, compare its **entire Jetton master address** with the address above. Unrelated parties can copy the name, ticker and logo. A TON Jetton wallet used to hold tokens has a different address from the Jetton master contract; do not confuse the two.

The public image URL is [policies.ilterra.com/assets/brand/ilterra_coin.png](https://policies.ilterra.com/assets/brand/ilterra_coin.png). It is a 256 × 256 PNG with a transparent background. The image helps identify the project visually but does not authenticate a token without the contract address.
